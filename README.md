# OrderSupportMacro（発注支援マクロ）

エリシアSを使う薬局で、処方回数のランキングから品目を A・B・C に区分し、A/B はエリシアSの自動発注（発注点の調整）に、C とフラグ品は毎日の手入力発注リストに振り分ける Excel VBA マクロ。

要件と設計は [docs/requirements.md](docs/requirements.md)・[docs/design.md](docs/design.md)、エリシアSの出力の確認手順は [docs/elixir-check-procedure.md](docs/elixir-check-procedure.md) にある。

## 運用の流れ

| いつ | 入力 | 出力 |
|---|---|---|
| 月初 | 前月分の出力ファイル（予測処方量は月単位でしか出力できない） | (1) 変更すべき発注点のリスト / (2) C分類の発注品目リスト |
| 毎日 | 予測処方量（向こう1週間分）・現在庫・発注残 | (3) 発注する数量のリスト（薬品単位。患者情報は載せない） |

## 今できていること（2026-10-24 時点）

エリシアSの出力の形式がまだ確認できていないため、入力の形式に左右されない計算の部分だけを先に作っている。

| モジュール | 内容 | 要件 |
|---|---|---|
| `AbcClassifier` | 順位と log(処方回数) に3本の折れ線を当てはめ、二乗誤差の合計が最小になる2つの折れ点を総当たりで探して、A/B・B/C の境界を求める。参考に累積構成比のひざも返す | F-02 |
| `OrderCalc` | 発注点・在庫上限（A/B）と、手入力発注の必要数（包装単位で切り上げ、在庫上限で頭打ち）と理由（C品目・要判断・分割発注・不足警告・マスタ未登録） | F-06・F-07・F-11〜F-13 |
| `AbcReport` | 区分を判定し、説明資料を作る。シート「分類レポート」に、結果のまとめ・判定の根拠の対数グラフ（点を区分ごとに色分けし、当てはめた直線・境界線・参考のひざを重ねる）・区間ごとの減り方の説明・判定の方法と条件・品目一覧を書き、`ABC分類レポート_<対象期間>.pdf` に書き出す | F-02・F-03 |
| `CalcTests` | 上の3つを架空のデータで確かめるテスト（分類レポートの PDF は `tests/out/` に出る） | — |

これから作るもの: 取り込み（F-01・F-10）、品目マスタと履歴（F-04・F-05）、出力のリスト（F-09・F-14・F-15）、薬局全体の在庫限界の調整（F-08。単位が未決）。

## 動作環境

- Windows 版の Excel（VBA が使えること）。店舗PC内で完結し、外部通信はしない
- 参照設定は不要

## セットアップ

1. Excel で新しいブックを開き、`Alt` + `F11` で VBE を開く。
2. 「挿入」→「標準モジュール」でモジュールを作り、`modules/` の各 `.bas` の中身をコピー＆ペーストする（1 行目の `Attribute VB_Name = ...` は除き、モジュール名をファイル名と同じにする）。`.bas` は UTF-8 なので、「ファイルのインポート」を使うと日本語が化ける。
3. マクロ有効ブック（`.xlsm`）として保存する。

実行ログとエラーログは `C:\VBAErrorLogs\ErrorLog_yyyymmdd.csv`（`ErrorLogger.bas`）。

## 開発

```
src/       編集用のソース (行番号なし、LF)
modules/   VBE に貼り付ける用 (行番号付き、CRLF)。src から生成する
tools/     ビルドと規約チェックのスクリプト
tests/     Excel を使った計算のテスト (データはすべて架空)
docs/      要件定義書・設計書・確認作業手順書 (現行版のみ)
archive/   改定前の文書と、配布した出力
input/     エリシアSの出力などの実データの置き場 (コミットしない)
```

```bash
python tools/vba_tools.py lint     # 規約チェック (GitHub/VBA/CLAUDE.md)
python tools/vba_tools.py build    # src -> modules (行番号を 10 刻みで付ける)
pwsh -File tests/run-tests.ps1     # Excel で計算のテストを実行する (FAIL があれば終了コード 1)
```

- `src/` を直したら `build` してから `modules/` も一緒にコミットする。
- `ErrorLogger.bas` は `GitHub/VBA/ErrorLogger.bas`（共有モジュール）のコピー。ここでは直さない。
- エリシアSの出力の列は、実ファイルを `GitHub/VBA/FileLayoutAnalyzer` で分析して確かめる（報告には値が出ない）。
