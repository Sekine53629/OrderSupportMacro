## 目的と使い方

エリシアSの発注・在庫・集計まわりの9画面について、出力形式・期間指定・出てくる項目の3点を現場で確認し、記録表に書き込むための手順書です。確認結果をもとに、自動発注と手打ち発注の品目分け（A/B/C分類）と、毎日の差分チェックの仕組みを設計します。

- 所要時間の目安：優先度Aの3画面で約20分、全9画面で約45分
- 実施タイミング：業務の落ち着いている時間帯（遅番の終業前など）
- 確認するだけで、設定の変更・発注・更新処理は行わない

## 確認の共通ルール

どの画面でも、次の3点を記録表に書き込みます。

- 出力形式：画面表示のみ／印刷のみ／PDF保存／CSV・Excel出力（ボタン名とファンクションキーもメモ）
- 期間指定：開始日・終了日を自由に入れられるか、月単位のみか、指定なしか
- 出てくる項目：薬品名・規格・数量のほか、処方回数・患者数・日付・在庫数・金額が出るか（列名をそのまま書き写す）

### 注意事項

- 患者氏名など患者情報が写る画面は、撮影・印刷・持ち出しをしない。項目名だけを書き写す
- 画面の撮影は、患者情報が写らない範囲（メニュー・条件入力画面・列名）に限る
- 「更新」「確定」「F12登録」などのボタンは押さない。終了はF12終了またはESCで戻る
- 出力ボタンがあっても、試しに出力するのはCSVの保存先を確認できる場合だけにする（店舗PC内に保存し、外部に持ち出さない）

## 優先度A：最初に確認する3画面

処方ランキングと発注点の自動算出に直結する画面です。ここだけでも先に確認できれば、設計を進められます。

### A-1 期間統計表（処方ランキングの元データ）

経路：メインメニュー F5 集計 → F3 期間統計表（どのタブからでも CTRL+F2 で開ける）

1. 期間統計表を開き、条件入力画面の項目をすべて書き写す
2. 集計の種類に「薬品別」「薬剤別」などの選択肢があるか確認する
3. 期間に直近3か月（例：2026/07/01〜2026/09/30）を入れられるか確認する
4. F10プレビューで、薬品ごとの列名を確認する（数量・処方回数・患者数・金額のどれが出るか）
5. 並び順を「数量順」「回数順」に変えられるか確認する
6. 出力ボタン（印刷・CSVなど）の種類を確認して、F12で終了する

### A-2 発注処理（発注の流れと発注DAT）

経路：F10 オプション1 → F1 薬品在庫 → F2 発注処理

1. 発注処理のサブメニューをすべて書き写す（マニュアル未収録の部分）
2. 自動発注の候補一覧を表示する画面があるか確認する（発注点を下回った品目が並ぶ画面）
3. 手打ち発注と自動発注が、同じ一覧に合流するか、別々に作られるか確認する
4. 送信前の発注内容を一覧で見られるか、その一覧を印刷・出力できるか確認する
5. 発注DATの作成・送信のボタン名を確認する（押さない）
6. 「4期」の切り替え方（期ごとの発注点の選択）がこの画面にあるか確認する

### A-3 適正在庫シミュレーション（発注点の自動算出）

経路：F5 集計 → F7 適正在庫シミュレーション

1. 条件入力画面の項目を書き写す（対象期間・安全係数・リードタイムなどがあるか）
2. 結果に「推奨発注点」「推奨在庫数」のような列が出るか確認する
3. 計算結果を発注点マスタへ一括反映する機能があるか確認する（反映は押さない）
4. 結果の出力形式を確認して、F12で終了する

## 優先度B：時間があれば確認する6画面

フラグ品の抽出、毎日の差分チェック、予定使用量の先読みに使う画面です。

### B-1 薬品実績（品目ごとの使用履歴）

経路：F10 オプション1 → F1 薬品在庫 → F1 薬品情報 → F2 薬品実績

1. 1品目（例：処方の多い品目）を呼び出し、表示される列名を書き写す
2. 日別・月別の使用量が見られるか、何か月分さかのぼれるか確認する
3. 複数品目をまとめて出力できるか確認する（1品目ずつなら集計向きではない）

### B-2 発注点（発注点の設定画面）

経路：F10 オプション1 → F1 薬品在庫 → F1 薬品情報 → F3 発注点

1. 1品目の設定項目を書き写す（発注点・発注量・在庫上限・4期それぞれの値など）
2. 発注点の一覧を出力できるか、一括で取り込める（インポート）機能があるか確認する
3. 自動発注の対象外にする設定（発注点0、自動発注しないフラグなど）がどれか確認する

### B-3 経過措置薬品リスト（フラグ品の抽出）

経路：F10 オプション1 → F1 薬品在庫 → F7 随時処理 → F3 経過措置薬品リスト

1. 条件入力画面と、一覧の列名（経過措置期限日・在庫数など）を書き写す
2. 在庫ありの品目だけに絞れるか確認する
3. 同じ画面のF1 不動品リスト、F2 期限切れリストの条件項目もあわせてメモする

### B-4 払出帳（毎日の使用量）

経路：F10 オプション1 → F1 薬品在庫 → F4 日次処理 → F3 払出帳

1. 日付を1日だけ指定して、品目ごとの払出数量が一覧で出るか確認する
2. 列名を書き写し、出力形式を確認する
3. F1 数量一覧の中身（在庫数の一覧か）もあわせて確認する
4. F10 払出更新は押さない（日次の更新処理のため）

### B-5 仕入帳（入った分）

経路：F10 オプション1 → F1 薬品在庫 → F4 日次処理 → F2 仕入帳

1. 日付を指定して、品目ごとの仕入数量・卸名・伝票番号が出るか確認する
2. 発注した分と納品された分を見比べられる項目（発注番号など）があるか確認する

### B-6 来局予定患者一覧（予定使用量の先読み）

経路：F5 集計 → F6 来局予定患者一覧

1. 条件入力画面の項目（予定日の範囲など）を書き写す
2. 患者単位の一覧か、薬品単位の集計（来週使う見込みの数量）も出せるか確認する
3. 患者情報が出る画面のため、列名だけを書き写し、撮影・印刷はしない

## 確認後の次のステップ

記録表が埋まったら、結果に応じて次のどれかに進みます。

- A-1またはB-1でCSV出力できる：直近3か月の薬品別データから、処方回数の累積曲線のひざで A/B/C の境界を決める
- A-3で推奨発注点が出る：自作の算出は省き、シミュレーション結果をA・B品目の発注点として使う
- 印刷しかできない：PDF保存して表を読み取る方法を検討する
- B-3で経過措置品を抽出できる：その品目の自動発注点を0にし、フラグ品として手打ち扱いにする
- B-4とA-2の一覧が出せる：毎日の「使用量 vs 発注量」の差分チェックリストを Excel／VBA で作る
