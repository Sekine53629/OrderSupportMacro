# CLAUDE.md — OrderSupportMacro (Tier 3)

Excel VBA macro for a pharmacy using the Elixir S receipt computer: classifies items
into A/B/C from prescription-count rankings, proposes reorder points for A/B items
(Elixir S auto-ordering), and lists daily manual orders for C and flagged items.
Follows Tier 1 (`GitHub/CLAUDE.md`) and Tier 2 (`GitHub/VBA/CLAUDE.md`).
Only project-specific decisions go here.

## Source documents

- `docs/requirements.md`, `docs/design.md`, `docs/elixir-check-procedure.md` are the
  current versions (Markdown copies of the user's .docx originals in `input/`).
  Follow Tier 1 "Document Version Management" when revising them.
- Where the two documents disagree, `requirements.md` wins (e.g. the A/B/C boundary
  is the 3-segment log fit of 4-1; the cumulative-share knee is only a reference value).

## Data and privacy

- Elixir S exports (prescription forecasts, visit schedules, stock lists) contain
  patient data. They go in `input/` and are never committed; workbooks holding
  imported data (`*.xlsm`, `*.xlsx`) are git-ignored.
- Patient-level rows may be used only inside calculations. Every output sheet and
  printout carries per-drug totals only (F-14).
- Do not read real patient values into the conversation. To learn an export's
  layout, run `GitHub/VBA/FileLayoutAnalyzer` on it (its report has no values).
- Test data is generated inside `CalcTests` and must be fictitious.

## Layout

- `src/` is the source of truth (no line numbers, LF). `modules/` is generated by
  `python tools/vba_tools.py build` (line numbers in steps of 10, CRLF). Commit both.
- `src/ErrorLogger.bas` is a copy of the shared `GitHub/VBA/ErrorLogger.bas`. Never edit it here.
- Run `python tools/vba_tools.py lint` and `pwsh -File tests/run-tests.ps1` before every commit.

## Project-specific rules

1. **Array-level procedures only.** `ErrorLogger.LogSuccess` rewrites the whole log
   file on each call, so logic that runs per item stays inline in a procedure that
   takes the whole item array (see `OrderCalc.CalcRequiredQty`).
2. **Rounding:** reorder points, stock upper limits and order quantities round up
   (`-Int(-x)`); order quantities are multiples of the pack size, and capping by the
   stock upper limit rounds down to a pack multiple and adds the "split order" reason.
3. **Reasons are bit flags** (`OrderCalc.REASON_*`); display text comes from
   `OrderCalc.ReasonTexts`, built once per run.
4. Importers (F-01, F-10) wait until the Elixir S export formats are confirmed
   (open items 3–8 in `requirements.md`). Do not guess column layouts.
5. VBA `And` / `Or` do not short-circuit. Guard array indexes with nested `If`.
6. The ABC classification must always ship with its explanation: `AbcReport.CreateAbcReport`
   writes the report sheet (summary, log-scale chart with class-colored points, fitted
   lines and boundaries, plain-language reading of each segment's slope, method and
   conditions, item list) and exports it to PDF. Keep the report drug-level only.
7. `ErrorLogger.LogError` clears `Err`; save `Err.Number` / `Err.Description` before
   logging when the error is re-raised.
